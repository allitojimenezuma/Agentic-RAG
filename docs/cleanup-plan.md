## What this project is

Agentic RAG maintains a persistent, interlinked Markdown wiki from raw documents. LLM
agents compile knowledge **once** into curated wiki pages; queries navigate + synthesize
over the curated wiki instead of repeated chunk retrieval.

```
raw/ (immutable) → 4 LangChain agents (ingest / query / lint / fix)
  → middleware: audit logging → path guardrails → token capture → HITL
  → wiki/ (pages + index.md + log.md; index is a derived view)
```

- CLI: `src/agentic_rag/cli.py` (ingest/query/lint/fix/status/log)
- Web UI: `frontend/` Streamlit multi-page app (same agents, in-process)
- Deterministic engine: `src/agentic_rag/wiki/` (model, BM25 search, matcher, index regen)
- Tests: `324 passed / 2 skipped` (verified baseline)

The mess: several design iterations (old index-based tools → consolidated nav tools;
manual index → regenerated index) were **layered, never removed**. Old tools, modules,
and the tests pinning them survive as dead weight.
