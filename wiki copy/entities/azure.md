# Azure

Microsoft's cloud computing platform offering a wide range of services including compute, storage, and AI services. [[Álvaro Jiménez Martínez]] used Azure-hosted large language models (LLMs) for [[Tool calling]] in the [[BHS Corrugated Spain]] project. The LLMs were integrated to fetch logs and restart services via APIs (Rundeck, Spring Boot Admin, Observium), enabling automated incident resolution.

## Services Used

- Azure OpenAI Service (assumed for LLM hosting)
- API integration for tool calling
