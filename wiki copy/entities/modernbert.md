# ModernBERT

An encoder-only transformer model designed by Answer.AI, optimized for embedding and classification tasks. It retains the BERT architecture while incorporating modern training techniques. [[Álvaro Jiménez Martínez]] implemented a native [[MLX]] version called mlx-modernBERT, enabling training on [[Apple Silicon]] for prompt-injection and PII detection tasks. The implementation includes full sequence and token classification heads.
