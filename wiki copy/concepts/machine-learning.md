# Machine Learning

Machine learning is a subset of artificial intelligence that enables systems to learn and improve from experience without being explicitly programmed.

## Key Facts

- **Focus**: Developing algorithms that can access data and use it to learn for themselves
- **Main types**: Supervised, unsupervised, reinforcement learning
- **Applications**: Image recognition, natural language processing, predictive analytics
