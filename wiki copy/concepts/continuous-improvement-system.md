# Continuous improvement system

An autonomous system that detects issues and optimizes its own performance over time. [[Álvaro Jiménez Martínez]] developed such a system at [[BHS Corrugated Spain]] incorporating two agents:

- **Recurrence agent**: Detected hardware failures by identifying 139 repeat issues from incident data.
- **Evaluation agent**: Auto-generated optimized system prompts to improve the AI's performance.

The system demonstrated autonomous problem-solving across ambiguous operational domains, continuously refining the AI workflow without manual intervention.
